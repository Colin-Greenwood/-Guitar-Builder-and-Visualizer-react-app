
# Custom Guitar Builder

## Route Plan

| URL | View |
|---|---|
| `/` | Home page with an introduction to the Custom Guitar Builder |
| `/items` | Displays all available guitar parts |
| `/items/:id` | Displays details about a selected guitar part |

## Application Description

The Custom Guitar Builder is a React application that allows users
to explore guitar components and view information about individual
parts.

## Technologies

- React
- Vite
- React Router
- JavaScript
- CSS
